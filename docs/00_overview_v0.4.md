# プロジェクト概要：AIスケルトン体験デモ

## プロジェクトの目的

MediaPipe を用いたリアルタイム骨格推定デモを実装し、大学オープンキャンパスで高校生に AI・コンピュータビジョンの面白さを体験させる。

ライブのカメラ入力に加えて、事前に撮影した動画ファイルを使った「事例コンテンツ」も再生・録画できる構造とし、展示準備や学外発表の素材作成にも転用できるようにする。

## 解決したい問題

「AI って難しそう」という高校生の先入観を取り除き、自分の体がリアルタイムでデジタル化される体験を通じて、AI への興味・進学意欲を高める。

## 想定ユーザー

- **メインユーザー**：オープンキャンパス参加の高校生（体験者）
- **サブユーザー**：展示を運営する大学スタッフ・教員（操作者）
- **サブユーザー**：撮影済みの動画素材から「動きの解析動画」を作りたい教員・学生

## ユースケース

### UC-01：オーバーレイ表示（モード1）
カメラ映像に骨格線をリアルタイムで重畳表示する。MediaPipe Pose Landmarker（新 API）の `num_poses` パラメータを用いて複数人対応を試みる。品質・パフォーマンスが不十分な場合は 1 人専用にフォールバックする。「AI が体を認識している」ことが直感的にわかる入口モード。

### UC-02：マネキン表示（モード2）
固定の風景写真を背景に、骨格データから生成した 3D マネキン（関節は球、骨はテーパード円柱、頭部は楕円体など）をリアルタイムで表示する。実写カメラ映像を半透明オーバーレイとして重ねて「実写と CG の対応」を見せる演出も可能。背景画像はファイルパスを設定で差し替え可能。複数人対応を試み、品質次第で 1 人にフォールバック。

### UC-03：3D 空間+キャラクター表示（モード3）
3D 空間（床・柱）を背景に、視点を自動回転させながら、骨格情報に連動して動くキャラクターをリアルタイム表示する。`pose_world_landmarks` を使って奥行きを伴った姿勢を再現する。キャラクターデザインは GLTF ファイルの差し替えで対応。複数人対応を試み、品質次第で 1 人にフォールバック。

### UC-04：モード切り替え
スタッフまたは高校生自身が `1` / `2` / `3` キーで各表示モードをその場で切り替えられる。GUI のボタンからも切り替え可能。切り替えはシームレスに行われ、カメラ映像は継続する。

### UC-05：展示起動・終了
スタッフがアプリを起動・終了できる。来客の入れ替えに際して特別な操作は不要。終了時に現在のスライダー設定が自動保存される。

### UC-06：動画ファイル再生（追加）
スタッフが「動画選択」ボタンまたは `V` キーで撮影済みの動画ファイルを開き、その動画に対する骨格推定結果を Mode2/3 で表示する。再生・一時停止・シーク・ループ・速度変更（0.5×〜10×）が画面下部のコントロールバーから可能。`C` キーでライブカメラに復帰できる。事前録画した運動映像の解析や、講演会・授業での事例提示に使える。

### UC-07：動画 MP4 書出（追加）
動画再生中に「動画書出」ボタンを押すと、入力動画と同じ解像度・FPS で Mode2 の見た目（マネキン＋実写オーバーレイ＋ボーン＋時系列グラフ）を MP4 として書き出せる。元動画の音声トラックは ffmpeg で自動 mux する。「サンプル書出」ボタンで先頭 300 フレームだけを短時間で確認できる。スタッフが撮影素材から「解析動画」を作って YouTube や学会発表で使うシナリオを想定。

### UC-08：パラメータの永続化（追加）
スライダーで調整したパラメータ（検出人数、平滑化α、グラフサイズ、トレイル設定、Mode2 太さ、Mode3 回転速度／視点角度など）は終了時に `user_settings.json` に自動保存され、次回起動時に復元される。スタッフが好みの見え方に調整した状態を毎回再現できる。

## 技術方針メモ（概要レベル）

- **実行環境**：Windows ノート PC（軽量動作を優先、必要に応じてデスクトップ機に移行）
- **骨格推定**：MediaPipe Pose Landmarker（新 API）、複数人は `num_poses` で試みフォールバック方針。指数移動平均（EMA）で平滑化
- **3D 描画**：PyOpenGL（PyQt6 + QOpenGLWidget）。ウィンドウサイズに依らず塗りつぶしコストを一定に保つため、内部 FBO 1280×720 に描画してから画面サイズに拡大表示する二段化構造
- **キャラクターデザイン**：GLTF ファイル差し替えで対応（`assets/characters/`）
- **背景画像**：設定ファイル（`config.yaml`）でパスを指定、差し替え可能
- **動画 I/O**：OpenCV の VideoCapture / VideoWriter。音声 mux は ffmpeg を subprocess で呼ぶ（Shotcut/Krita/OBS 同梱版も自動検出）
- **時系列グラフ**：pyqtgraph で右上にオーバーレイ表示
- **設定の二層管理**：システム設定（カメラ番号、解像度、モデルパス等）は `config.yaml`、ユーザー調整値（スライダー値等）は `user_settings.json`（git 管理外、起動時 load／終了時 save）
- **状態管理**：`AppSettings`（パラメータ Model）と `PoseStream`（フレームブローカ）を導入し、MainWindow は wiring 専任に分離
