# プロジェクト概要：AIスケルトン体験デモ

## プロジェクトの目的

MediaPipe を用いたリアルタイム骨格推定デモを実装し、
大学オープンキャンパスで高校生に AI・コンピュータビジョンの
面白さを体験させる。

## 解決したい問題

「AIって難しそう」という高校生の先入観を取り除き、
自分の体がリアルタイムでデジタル化される体験を通じて、
AI への興味・進学意欲を高める。

## 想定ユーザー

- メインユーザー：オープンキャンパス参加の高校生（体験者）
- サブユーザー：展示を運営する大学スタッフ・教員（操作者）

## ユースケース

### UC-01：オーバーレイ表示（モード1）
カメラ映像に骨格線をリアルタイムで重畳表示する。
MediaPipe Pose Landmarker（新API）のnum_posesパラメータを用いて
複数人対応を試みる。品質・パフォーマンスが不十分な場合は1人専用にフォールバックする。
「AIが体を認識している」ことが直感的にわかる入口モード。

### UC-02：マネキン表示（モード2）
固定の風景写真を背景に、骨格データから生成した
シンプルな人型（マネキン）をリアルタイムで表示する。
カメラ映像は表示せず、現実空間にデジタル人間が
立っているような演出を行う。
背景画像はファイルパスを設定で差し替え可能とする。
複数人対応を試みる。品質・パフォーマンスが不十分な場合は1人専用にフォールバックする。

### UC-03：3D空間+キャラクター表示（モード3）
ゆっくり視点回転する 3D 空間を背景に、
骨格情報に連動して動くキャラクターをリアルタイム表示する。
キャラクターデザインは後から差し替え可能な構造とする。
初期実装はシンプルな人型。
複数人対応を試みる。品質・パフォーマンスが不十分な場合は1人専用にフォールバックする。

### UC-04：モード切り替え
スタッフまたは高校生自身が 1・2・3 キーで
各表示モードをその場で切り替えられる。
切り替えはシームレスに行われ、カメラ映像は継続する。

### UC-05：展示起動・終了
スタッフがアプリを起動・終了できる。
来客の入れ替えに際して特別な操作は不要。

## 技術方針メモ（概要レベル）

- 実行環境：Windows ノート PC（軽量動作を優先、必要に応じてデスクトップ機に移行）
- 骨格推定：MediaPipe Pose Landmarker（新API）、複数人はnum_posesで試みフォールバック方針
- 3D 描画：PyOpenGL（PyQt6 + QOpenGLWidget経由）
- キャラクターデザイン：差し替え可能な構造を設計段階から担保する
- 背景画像：設定ファイルでパスを指定、差し替え可能
