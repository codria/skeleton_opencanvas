# 機能要件定義：AIスケルトン体験デモ

## 実装する機能（Goals）

### F-01：リアルタイム骨格推定
- カメラ映像から人体の骨格をリアルタイムで推定する
- MediaPipe Pose Landmarker（新API）を使用し、num_posesパラメータで
  複数人検出を試みる（目安：2〜3人）
- 品質・パフォーマンスが不十分な場合は1人専用にフォールバックする
- 推定ライブラリ：mediapipe（Pose Landmarker）

### F-02：モード1 ― オーバーレイ表示
- カメラ映像をそのまま背景として表示する
- 検出した骨格を線と点でリアルタイムに重畳描画する
- 複数人分の骨格を同時に描画する（F-01のフォールバック方針に準ずる）

### F-03：モード2 ― マネキン表示
- 設定ファイルで指定した固定の風景写真を背景として表示する
- 骨格データをもとにシンプルな人型（マネキン）を 2D で描画する
- カメラ映像は表示しない
- 複数人分のマネキンを同時に描画する（F-01のフォールバック方針に準ずる）
- 背景画像はファイルパスの変更のみで差し替え可能とする
- マネキンのデザインはファイルや設定の変更のみで差し替え可能な構造とする

### F-04：モード3 ― 3D キャラクター表示
- ゆっくり視点回転する 3D 空間を背景として描画する
- 骨格データに連動して動くシンプルな人型キャラクターを表示する
- キャラクターデザインは後から差し替え可能な構造とする（初期実装はシンプルな人型）
- 複数人対応を試みる（F-01のフォールバック方針に準ずる）

### F-05：モード切り替え
- キーボードの 1・2・3 キーで各モードをその場で切り替えられる
- 切り替え時もカメラキャプチャは継続し、映像が途切れない

### F-06：アプリ起動・終了
- コマンド一発でアプリを起動できる
- Q キーまたは Esc キーでアプリを終了できる

### F-07：設定ファイル
- 背景画像パス、カメラデバイス番号、カメラ解像度（width/height）、
  FPS など、環境依存の設定を外部ファイル（config.yaml）で管理する
- コードを変更せずに設定を切り替えられる
- ダイアログ等で変更した値はランタイム上書きで即時反映できる
  （ファイルへの書き戻しは行わない）

### F-08：GUI コントロールパネル
- PyQt6 製のウィンドウ上にカメラ映像・描画結果を表示する
- モード切り替えボタンを GUI 上に配置する
- 背景画像のファイル選択をダイアログから行えるようにする

### F-09：画面上の操作ガイド表示
- 現在のモード名を画面上に常時表示する
- キー操作の説明（1・2・3キーでモード切り替え、Qで終了）を
  画面上に常時表示する
- 表示位置・サイズはデモの邪魔にならないよう配慮する
- F キーでFPS・デバッグ情報の表示／非表示を切り替えられる
  （デフォルトは非表示）

### F-10：起動時のカメラ確認
- 起動時にカメラへの接続を確認し、映像が取得できているかを検証する
- カメラが見つからない・映像が取得できない場合は
  エラーメッセージを画面上に表示してアプリを安全に終了する

## 実装しない機能（Non-Goals）

- スクリーンショット保存機能
- 音声・BGM 再生
- ネットワーク通信・クラウド連携
- GUI 設定画面（設定はファイル編集で行う）
- スマートフォン・タブレット対応
- インストーラーの作成（スタッフが手動でセットアップする前提）
- 画面上のカメラ範囲ガイド表示（床のテープで代替する運用とする）
- 異常終了時の自動復旧（再起動による手動対応をRunbookに記載する）

## 技術スタック

| 用途 | 技術 |
|------|------|
| 骨格推定 | MediaPipe Pose Landmarker（新API） |
| GUI フレームワーク | PyQt6 |
| 3D 描画（モード3） | PyOpenGL（PyQt6 + QOpenGLWidget経由） |
| カメラ・画像処理 | OpenCV（opencv-python） |
| 設定ファイル | PyYAML |
| 数値計算 | NumPy |
| 言語 | Python 3.10以上 |

---

## スコープ補足

- 実行環境は Windows ノート PC を第一ターゲットとする
- 軽量動作を優先し、重い場合はデスクトップ PC への移行を許容する
- 複数人対応はMediaPipe Pose Landmarkerのnum_posesで試み、
  品質・パフォーマンスが不十分な場合は1人専用にフォールバックする
